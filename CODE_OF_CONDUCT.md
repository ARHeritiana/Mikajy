# Code of Conduct

Be kind and constructive. Critique code and ideas, not people. Harassment, discrimination and personal attacks
are not tolerated. Maintainers may remove comments, issues or contributions that break these rules and may
block repeat offenders. Report problems privately to the repository owner through GitHub.

This project follows the spirit of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
